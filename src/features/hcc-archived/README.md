# HCC (Archived) worklist

This tree is a **frozen snapshot** of the HCC worklist UI. It exists so demos and regression checks can open "HCC (Archived)" without picking up ongoing changes under `src/features/hcc/`.

Do not copy fixes from `hcc/` into here unless the archived experience must change on purpose. Prefer changing `hcc/` for product work.

Long term, consider replacing this duplicate tree with a version pin or feature flag on shared modules so two full copies of upload/diag drawers are not maintained.
